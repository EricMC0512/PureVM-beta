# 🖤 PureVM-beta

A pure black, ultra-lightweight container designed for touchscreens.

## 🚀 Vision
Break down system barriers and squeeze every drop of hardware performance. 
We pack multi-system applications like Windows (`.exe`) and Linux (`.deb`) into a minimalist black box. No bloated desktops, no flashy animations—just pure performance and immersion.

## ✨ Features
*   🖤 **Minimalist Black Box UI**: Completely hides the system desktop for full-screen immersive execution.
*   👆 **Touch Gestures Mapping**:
    *   **Single Tap** = Left Click
    *   **Long Press** = Right Click
    *   **Two-Finger Long Press (Edge)** = Global App Menu
*   🖱️ **Virtual Trackpad**: A floating trackpad designed for precision, perfectly restoring the PC experience.
*   ⚡ **Ultra-low Resource Usage**: Highly optimized bottom layer to minimize memory footprint.
*   🪟 **Multi-Container Support**: Manage multiple background processes as easily as switching native apps.

## 🛠️ Tech Stack
*   **Frontend (UI)**: Java / Kotlin (Android Studio)
*   **Backend (Core)**: C/C++ (Wine / Box64 / NDK)
*   **Hardware**: GPU Hardware Acceleration + JIT (Optimized for low-level Android & iOS)

# 🇨🇳 中文介绍

**PureVM-beta：一个专为触屏设计的纯黑、超轻量级多系统容器。**

## 🚀 核心愿景
打破系统壁垒，榨干每一滴硬件性能。我们将 Windows (`.exe`)、Linux (`.deb`) 等多系统应用塞进一个极简的黑盒中。没有臃肿的桌面，没有花里胡哨的动画，只有纯粹的性能与沉浸感。

## ✨ 革命性交互
*   🖤 **极简黑盒 UI**：彻底隐藏系统桌面，全屏沉浸式运行。
*   👆 **触屏映射**：
    *   **单击** = 鼠标左键
    *   **长按** = 鼠标右键
    *   **双指长按黑边** = 呼出全局应用菜单
*   🖱️ **虚拟触控板**：专为精细操作打造的悬浮触控板，完美还原 PC 体验。
*   ⚡ **极低占用**：底层精简，将内存占用压缩到极致。
*   🪟 **多开容器**：像切换原生 App 一样，轻松管理多个后台进程。

## 🛠️ 技术栈
*   **前端 (UI)**: Java / Kotlin (Android Studio)
*   **底层 (核心)**: C/C++ (Wine / Box64 / NDK)
*   **硬件加速**: GPU 硬件加速 + JIT (针对安卓和 iOS 底层优化)
